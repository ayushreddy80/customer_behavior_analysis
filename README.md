Overview

This project focuses on end-to-end data analytics using Python, SQL, and Power BI. It includes data loading, cleaning, exploratory data analysis (EDA), SQL querying, dashboard creation, and report generation to extract meaningful business insights.

The project demonstrates practical analytics skills commonly used in real-world data analyst roles.

Dataset

The dataset used in this project contains business/financial-related information such as sales, profits, customers, products, and regional performance.

Data sources can include:

CSV files
Excel files
PostgreSQL / MySQL / SQL Server databases
